# Status report formatter

1. Ask for (or use what's already in the conversation) a raw list of updates —
   plain bullet points, no particular order.
2. Sort each item into **Done**, **In Progress**, or **Blockers** based on its
   wording (past tense / "finished" → Done; "working on" → In Progress;
   "waiting on" / "blocked by" → Blockers).
3. Render using the template in `reference.md` — read that file before writing
   the final output.
4. If an item is ambiguous, ask rather than guessing which section it belongs in.
